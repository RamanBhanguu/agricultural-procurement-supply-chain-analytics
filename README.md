# Agricultural Procurement & Supply Chain Analytics

A Power BI analytics project examining procurement spending, supplier performance, inventory value, order activity, and delivery performance for an agricultural supply chain scenario.

## Business Problem

Agricultural businesses need visibility into procurement spending, inventory, order activity, and delivery performance to support better purchasing and operational decisions.

This project creates a consolidated analytical view of these areas using Power BI.

## Business Questions

The dashboard focuses on questions such as:

- How much are we spending on procurement?
- Which suppliers account for the highest procurement spend?
- Which products drive procurement spending?
- Where is inventory value concentrated?
- How many orders are being processed?
- What is the current delivery performance?
- How does procurement spending change over time?

## Data Model

The Power BI model uses multiple operational tables including:

- Products
- Suppliers
- Orders
- Order Lines
- Purchasing
- Inventory
- Deliveries
- Date

The model uses relationships between fact and dimension-style tables to support integrated reporting.

## Data Preparation

Data was prepared and validated before dashboard development.

Activities included:

- Data quality review
- Removal of invalid records
- Handling of known data issues
- Validation of business fields
- Relational modeling
- Date-based analysis preparation

## Power BI & DAX

The dashboard uses DAX measures for:

- Total Procurement Spend
- Purchase Orders
- Average Purchase Cost
- Total Inventory Value
- Total Orders
- Total Deliveries
- Delivered Deliveries
- Delivered %

## Dashboard

The dashboard provides:

- KPI cards
- Procurement by Supplier
- Procurement by Product
- Inventory Value by Product
- Procurement Trend
- Delivery Performance
- Year filtering
- Month filtering

## Key Results

The completed dashboard provides visibility into approximately:

- $1.93M procurement spend
- 89 purchase orders
- 1M inventory value
- 260 total orders
- 89% delivered

Delivery status analysis includes:

- Delivered
- Delayed
- In Transit
- Canceled

## Business Insights

The dashboard supports analysis of:

- Supplier spending concentration
- Product-level procurement costs
- Inventory value concentration
- Delivery performance
- Procurement trends over time

## Business Recommendations

Potential actions supported by the analysis include:

- Monitor high-spend suppliers
- Review procurement spending by product
- Monitor high-value inventory
- Investigate delayed deliveries
- Review canceled and in-transit deliveries
- Use monthly and yearly analysis for ongoing performance reviews
